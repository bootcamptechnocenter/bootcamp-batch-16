### Bagian A — Jawaban Kuis Prediksi Output

**Soal 1 — Integer Division**
```
int a = 7, b = 2;
Console.WriteLine(a / b);           // Output: 3   (integer division, dibulatkan ke bawah)
Console.WriteLine((double)a / b);   // Output: 3.5 (cast ke double dulu)
```
> 💡 Poin diskusi: `int / int` di C# **selalu menghasilkan int**. Untuk mendapat desimal, minimal satu operand harus `double` atau `decimal`.

---

**Soal 2 — Nullable Operator**
```
string? nama = null;
Console.WriteLine(nama ?? "Tidak diketahui");  // Output: Tidak diketahui
Console.WriteLine(nama?.Length);               // Output: (baris kosong)
```
> 💡 `??` = null-coalescing: ambil kanan jika kiri null. `?.` = null-conditional: hasilnya null jika objek null (tidak throw exception). `Console.WriteLine(null)` mencetak baris kosong.

---

**Soal 3 — Mana yang Error Compile**
```
int x = 3.14;       // ❌ ERROR: cannot implicitly convert 'double' to 'int'
double y = 3.14;    // ✅ OK
var z = 3.14;       // ✅ OK — z diinfer sebagai double
decimal d = 3.14;   // ❌ ERROR: literal 3.14 adalah double, harus tulis 3.14m
```
> 💡 Perbaikan: `int x = (int)3.14;` atau `decimal d = 3.14m;`

---

**Soal 4 — Operator Precedence**
```
int hasil = 10 + 3 * 2 - 8 / 4;
// Urutan: 3*2=6, 8/4=2, lalu 10+6-2 = 14
Console.WriteLine(hasil);  // Output: 14
```
> 💡 Sama seperti matematika: `*` dan `/` dikerjakan sebelum `+` dan `-`.

---

**Soal 5 — TryParse vs Parse**
```
string input = "abc";

// A — CRASH dengan FormatException
int.Parse(input);

// B — AMAN, return false, harga = 0
bool ok = int.TryParse(input, out int harga);
Console.WriteLine(ok);    // false
Console.WriteLine(harga); // 0
```
> 💡 Aturan praktis: `Parse` untuk data yang **sudah pasti valid** (misal dari database). `TryParse` untuk **input user**.

**Tantangan 1 — Hitung Cicilan Kendaraan**
```

decimal dp            = hargaKendaraan * persenDP;
decimal pokok         = hargaKendaraan - dp;
decimal totalBunga    = pokok * bungaPerBulan * tenor;
decimal cicilanPerBulan = (pokok + totalBunga) / tenor;

Console.WriteLine($"Harga       : Rp {hargaKendaraan:N0}");
Console.WriteLine($"DP (30%)    : Rp {dp:N0}");
Console.WriteLine($"Pokok       : Rp {pokok:N0}");
Console.WriteLine($"Bunga/bln   : Rp {pokok * bungaPerBulan:N0}");

```

> 💡 Tekankan: semua perhitungan uang pakai `decimal`, bukan `double`. Format `:N0` otomatis tambah titik ribuan.

### Try-Catch

> *"Error handling = sabuk pengaman. Program yang baik tidak crash  ia menangkap error dan memberi pesan yang berguna."*

```
try
{
    Console.Write("Masukkan angka: ");
    string input = Console.ReadLine()!;
    int    angka = int.Parse(input);              // FormatException kalau bukan angka
    Console.WriteLine($"Dua kali: {angka * 2}");
}
}
catch (FormatException)
    // ... (kode lengkap ada di presentasi-pengajar.html untuk dipraktikkan bersama pengajar) ...
}
}
}
```

### VIEW

> *"View adalah 'query yang disimpan'. Setiap kali SELECT dari view, query di baliknya langsung dieksekusi. Berguna untuk menyederhanakan query panjang."*

```
CREATE OR REPLACE VIEW v_active_brands AS
SELECT
    id,
    code,
    name,
    created_at::DATE AS created_date
FROM   mst_brands
WHERE  deleted_at IS NULL
AND    is_active  = TRUE
ORDER  BY name;

-- Pakai view seperti tabel biasa
SELECT * FROM v_active_brands;
SELECT * FROM v_active_brands WHERE name ILIKE '%hon%';
```

** PERTANYAAN PANCINGAN:**
| Pertanyaan | Jawaban |
|---|---|
| "Apa bedanya procedure dan function di SQL?" | Function harus return nilai, bisa pakai di SELECT. Procedure dipanggil dengan CALL |
| "Kapan pakai stored procedure vs query di kode C#?" | SP: logika kompleks yang lebih efisien di DB, atau shared antar banyak aplikasi |
